**Customer Support Ticket Analyser**

**Project Overview**

The Customer Support Ticket Analyser is a Python-based project designed to store, clean, and analyze customer support ticket data.

The system works with customer names, issue descriptions, ticket priorities, and ticket numbers. It also provides useful insights such as keyword frequency, priority distribution, the longest issue description, and unique words used in customer issues.

**Features**

- Stores preloaded customer support tickets

- Allows users to add new tickets

- Automatically generates ticket numbers

- Validates ticket priority as High, Medium, or Low

- Cleans issue descriptions

- Converts text to lowercase

- Removes punctuation and extra spaces

- Replaces simple slang/shorthand

- Counts tickets containing specific keywords

- Analyzes ticket priorities

- Finds the ticket with the longest issue description

- Extracts and sorts unique words

**How to Run**

**Step 1: Install Python**

Make sure Python is installed on your computer.

**Step 2: Download or clone the repository**

Download this repository to your computer.

**Step 3: Open the project**

Open the project folder in VS Code or another Python editor.

**Step 4: Run the program**

Run:

python ticket_analyser.py

**Step 5: Add tickets**

The program will ask how many new tickets you want to add. Enter the required number and provide:

- Customer Name

- Issue Description

- Priority

- The priority must be High, Medium, or Low.

- Analysis Performed

The program provides the following analysis:

- Keyword Analysis

- Counts the number of tickets containing:

poor

good

slow

excellent

- Priority Analysis

- Calculates the number of:

High-priority tickets

Medium-priority tickets

Low-priority tickets

- Longest Issue Description

- Identifies the ticket with the highest number of words and displays:

- Ticket number

- Customer name

- Cleaned issue description

- Word count

- Unique Words

- Creates a set of all words used in the issue descriptions and displays the total number of unique words along with the sorted word list.
